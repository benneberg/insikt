INSIKT

A mobile-first debugging overlay for the browser. Tap the ⌥ button to open the panel, then trigger events below to see it in action.

Trigger events

What's inside

  • Console — log/warn/error/info with timestamps, object pretty-print, REPL with history
  • Network — Fetch and XHR interception, method badges, status, duration, URL filtering
  • Storage — IndexedDB explorer, LocalStorage and SessionStorage viewer, cookies
  • DOM — collapsible live tree, element picker with hover highlight, attribute inspector
  • System — screen, user agent, memory, connection, battery, permissions
  • Settings — timestamps, auto-scroll, max entries, font size, theme, monitoring toggles
